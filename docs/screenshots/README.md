# Screenshots

Images referenced from [README.md](../../README.md) and
[SETUP.md](../SETUP.md) live here.

Capture them at a 1280×800 desktop window (and 390×844 for the phone shot), in
light mode, from an instance loaded with the demo data
(`npm run db:demo`) so no real person's details are published.

| File | What to capture |
| --- | --- |
| `dashboard.png` | Home — "This week" and "My upcoming dates" |
| `plan.png` | A published plan: order of service on the left, People panel on the right |
| `matrix.png` | Services → Matrix, a few weeks across, with cells filled |
| `request-phone.png` | The `/respond/<token>` page on a phone-width viewport |
| `settings-church.png` | Settings → Church, showing the logo and accent picker |

Keep them under ~300 kB each; PNG is fine. Re-shoot after any significant UI
change so the docs do not drift from the app.
