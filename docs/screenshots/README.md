# Screenshots

Images used by [README.md](../../README.md) and [SETUP.md](../SETUP.md).

| File | What it shows |
| --- | --- |
| `dashboard.png` | Home — "This week" and "My upcoming dates" |
| `plan.png` | A published plan: order of service with the running clock |
| `matrix.png` | Services → Matrix, three services side by side |
| `request-phone.png` | The `/respond/<token>` page at phone width |
| `settings-church.png` | Settings → Church — logo tiles and the accent picker |

All shots come from a local instance loaded with the demo data
(`npm run db:demo`), in light mode at 1280×800 (390×844 for the phone one),
2× device pixel ratio — so no real person's details are ever published.

Re-shoot after a significant UI change, keeping the same filenames and roughly
the same framing so the docs do not drift from the app. Keep each file under
about 300 kB.
